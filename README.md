# SOC: Smart Security Log Analyzer with Intelligent Incident Triage

## 📌 Project Overview

The **Smart Security Log Analyzer** is a security application designed to analyze security logs, identify suspicious activities, and support intelligent incident triage. It helps users understand potential security threats and investigate unusual events more efficiently.

## 🎯 Objectives

- Analyze security logs to identify suspicious activities.
- Detect potentially malicious events and unusual patterns.
- Support security incident investigation and prioritization.
- Improve the efficiency of security monitoring and analysis.

## ✨ Key Features

- **Security Log Analysis:** Process and examine security-related log data.
- **Threat Identification:** Highlight suspicious events that may indicate security threats.
- **Incident Triage:** Help assess and prioritize security incidents.
- **Audit Logging:** Maintain records of relevant application activities.
- **User Interface:** Provide an interface for interacting with the application.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Sushintha18/smart-log-analyzer.git
   ```

2. Open the project folder in Visual Studio Code.

3. Create and activate a Python virtual environment if required.

4. Install the dependencies listed in your project's requirements file, if available.

5. Configure the required environment variables and application settings.

6. Run the application using the appropriate command for your configured frontend and backend.
